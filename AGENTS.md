# AGENTS.md

Спільна локальна інфраструктура сервісів Laba: один Traefik, мережа `laba_network`, реєстр
сервісів `services.yaml` і команди Makefile, що клонують і піднімають сервіси. Як це працює
для людей — у `README.md`.

Відповідай і пиши документацію українською; код, коментарі в коді й Makefile — англійською.

## Де що в Laba і за якими правилами

```
Laba/
├── Traefik/              цей репозиторій: інфраструктура й реєстр сервісів
├── Services/<service>/   сервіси з template-symfony-service — правила в їхньому AGENTS.md
└── Bundles/
    ├── template-symfony-bundle/         шаблон бандла — правила структури в AGENTS.md
    ├── template-symfony-client-bundle/  шаблон клієнта сервісу — правила в AGENTS.md
    ├── template-symfony-service/        шаблон сервісу — правила в AGENTS.md
    └── <Name>Bundle/                    бандли; еталон структури — RequestBundle
```

Цей файл підхоплюється в кожній сесії під `Laba/` через `Laba/CLAUDE.md` (його створює
`make claude-md`); тримай його коротким і загальним, правила окремих репозиторіїв — у їхніх `AGENTS.md`.

Усі репозиторії Laba пишуться в одному стилі. Перш ніж створювати або змінювати бандл, клієнт чи
сервіс, прочитай `AGENTS.md` його шаблону, навіть якщо в самому репозиторії такого файлу ще немає.

- Новий бандл або клієнт — з шаблону в `Bundles/`, за його `INIT_BUNDLE.md`.
- Новий сервіс — з `template-symfony-service`, за його `INIT_SERVICE.md`; той сам реєструє сервіс тут.

## Цей репозиторій

- **`services.yaml` — єдине місце, де описано сервіс.** Новий сервіс — один блок там, з `db_port`
  наступним у серії (33061, 33062, ...). Поля пояснено на початку файлу.
- **Формат реєстру плаский навмисно:** його читає `bin/registry.py` регулярними виразами, без PyYAML.
  Не вводь вкладеності, якорів, багаторядкових значень чи списків, яких там ще немає; новий формат —
  лише разом зі зміною `registry.py`. Скрипти `bin/` — Python 3 лише зі стандартною бібліотекою.
- **Згенероване не правиться вручну:** `generated/` і `dynamic/fallback-*.yml` створює `make gen`
  з реєстру. Спільні middleware — у `dynamic/middleware.yml`, його можна правити.
- **Секрети:** справжні `api_key` — лише в `services.local.yaml` (gitignored); у `services.yaml`
  завжди `api_key: null`. У `.env.local` сервісів ключі пише `make secrets`, а не рука.
- **Хости:** `<service>.localhost` — для браузера, `<service>.local` — для викликів між сервісами
  (усередині контейнера `*.localhost` резолвиться в сам контейнер). Будь-яка `*_URL` до іншого
  сервісу — на `.local`.

## Перевірка

Після зміни `services.yaml` або `bin/`:

```bash
make check   # дублікати db_port / хостів, невідомі учасники груп
make gen     # генерація без помилок
```

Зміну Makefile або `traefik.yml` перевір на живому Traefik: `make traefik-up`, далі
`curl -s http://127.0.0.1:8080/api/http/routers` і `logs/access.log`.

## Не робити

- Не комітити без явного прохання.
- Не змінювати репозиторії сервісів і бандлів без згоди користувача: `make` тут лише викликає їхні
  власні команди.
- Не запускати `make down` / `make stop` / `make checkout` без прохання: вони зачіпають сервіси,
  з якими користувач може працювати.
